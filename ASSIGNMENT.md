# Assignment "Discovery Writing"
## Instructions
1. Ask with the GitHub CoPilot plugin in "Agent mode" to add draft feature:
``Please add the draft feature to this application, allowing users to draft articles instead of publishing them directly.``

3. Once the agent finishes, review the code changes and discuss with each other about the implementation.
