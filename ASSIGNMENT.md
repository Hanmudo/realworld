# Assignment "Agentic Spec Driven Development"
## Instructions
1. Specify a feature with the Analyst agent, ensuring it is clear and concise. The Analyst agent is already provided in the .github folder.
2. Plan the feature with the Lead developer agent.
3. Implement the feature with the Developer agent.
4. Review it's outcome and when necessary, iterate on tweaking the agents' specifications.
5. Start the application and verify the feature works as expected.
6. Manually test the functionality and check for bugs, are there any? What did you expect?
